# Fancy Tales Documentation

This folder contains the public, non-sensitive documentation for Fancy Tales.

## Documents

- [Project overview](PROJECT_OVERVIEW.md) — product purpose, audience, and guiding decisions.
- [Development status](DEVELOPMENT_STATUS.md) — features reported as implemented, partially implemented, and still requiring verification.
- [Roadmap](ROADMAP.md) — suggested next phases from product stabilization through launch.

## Documentation principles

- Distinguish verified functionality from reported or planned functionality.
- Do not store credentials, tokens, private user information, production configuration, or detailed security vulnerability information in this public repository.
- Security remediation SQL belongs in a controlled, reviewed workflow. Draft SQL must not be placed in executable migrations.
- Update these documents when product decisions or implementation status change.
