# Fancy Tales — Project Overview

## Product summary

Fancy Tales is a reading and storytelling platform for discovering original novels, stories, and memorable adventures. It is intended to support both readers and writers in one community.

**Tagline:** Read. Imagine. Remember.

## Product direction

- Begin with a Nigeria-first launch.
- Build toward broader African reach, followed by international availability.
- Support both free and paid stories.
- Allow any registered user to become an author, subject to the platform's content rules.
- Give authors tools to manage their own stories and chapters.
- Prioritize a welcoming reader experience, story covers, author profile pictures, bookmarks, and reading progress.

## Intended audiences

### Readers
People who want to discover, read, save, and follow their reading progress across stories.

### Authors
People who want to create stories, organize chapters, present an author profile, and make stories available to readers.

## Product principles

1. **Accessible publishing:** registration should not be restricted to a special author-only group.
2. **Reader-focused design:** reading, discovery, bookmarks, and progress are core experiences.
3. **Author ownership:** authors should manage their own content.
4. **Trust and safety:** community rules, moderation, privacy, and secure access are necessary for launch.
5. **Evidence-based delivery:** mark a feature complete only after it has been tested in the target environment.

## Current technical context

The project has been developed with React and Vite and uses Supabase for authentication, database, and storage functionality. Exact production configuration and deployment status must be verified separately.
